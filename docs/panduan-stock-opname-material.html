Panduan Stock Opname Material

Portal Asset - SOP Penggunaan Modul Stock Opname

Versi: 1.1

Tanggal: 24 Agustus 2026

Role bawaan: Admin, Estate, Manager

Menu: Inventory > Stock Opname

Prinsip utama: hasil hitung fisik tidak langsung mengubah stok material. Stok hanya berubah setelah sesi diajukan, disetujui melalui workflow, dan status menjadi Posted.

1. Tujuan Modul

Modul Stock Opname Material dipakai untuk membandingkan stok sistem dengan stok fisik di lapangan, mencatat selisih, meminta review/approval, lalu memposting adjustment resmi ke stok material dan transaksi.

  • Membuat snapshot stok sistem pada tanggal opname.
  • Mengisi hasil hitung fisik manual atau melalui import CSV.
  • Mewajibkan alasan jika ada variance.
  • Menyediakan workflow approval sebelum adjustment diposting.
  • Menyediakan export CSV dan PDF Berita Acara setelah Posted.

2. Role dan Tanggung Jawab

Role Tanggung Jawab Permission Kunci
Admin Monitoring semua estate, membuat sesi untuk estate tertentu, konfigurasi workflow, approval final bila ditunjuk di workflow, dan download laporan. Semua permission Stock Opname.
Estate Membuat sesi untuk estate sendiri, melakukan counting, import CSV, submit review, cancel sebelum approval, dan export. View, create, edit, count, submit, cancel, export.
Manager Review variance, meminta recount jika perlu, submit approval, dan melihat/export sesi sesuai akses estate. Estate permission + review.
Jika final approver tidak memakai role Finance, gunakan role Admin atau Manager pada workflow Material Stock Opname sesuai kebijakan internal.

4. Persiapan Sebelum Opname

  • Pastikan user sudah aktif dan memiliki role yang benar.
  • Pastikan user memiliki estate, kecuali Admin yang boleh mengelola lintas estate.
  • Pastikan master material sudah lengkap: kode, nama, unit, section, harga, dan stock awal.
  • Pastikan workflow Material Stock Opname aktif dan memiliki approver.
  • Pastikan tidak ada sesi aktif lain untuk estate dan section yang sama.

5. Langkah Penggunaan

Step 1 - Login
  1. Buka Portal Asset melalui browser.
  2. Masukkan username dan password.
  3. Jika login berhasil, sistem masuk ke Dashboard.
  4. Jika user diarahkan kembali ke Dashboard saat membuka menu lain, cek status aktivasi, estate, dan permission role.
Step 2 - Masuk ke Menu Stock Opname
  1. Buka sidebar kiri.
  2. Pilih Inventory.
  3. Klik Stock Opname.
  4. Halaman menampilkan daftar sesi, filter estate, filter status, dan pencarian.
Jika menu tidak muncul, cek permission view-material-stock-opnames pada role user dan lakukan logout-login setelah permission diperbarui.
Step 3 - Buat Sesi Baru
  1. Klik New Session.
  2. Admin atau user HO memilih Estate. User Estate memakai estate miliknya.
  3. Pilih Opname Date.
  4. Pilih Section jika opname hanya untuk section tertentu. Kosongkan untuk semua section.
  5. Isi Notes bila perlu.
  6. Klik Create Snapshot.
Snapshot menyimpan stok sistem saat sesi dibuat. Ini menjadi dasar perbandingan dengan hitung fisik.
Step 4 - Mulai Counting
  1. Buka detail sesi dari daftar Stock Opname.
  2. Pastikan status masih Draft.
  3. Klik Start Counting.
  4. Status berubah menjadi Counting.
Step 5 - Isi Hasil Hitung Manual
  1. Buka tab Items.
  2. Gunakan Search Items untuk mencari kode material, nama material, atau section.
  3. Isi kolom Physical sesuai hasil hitung fisik.
  4. Isi Recount jika ada hasil hitung ulang.
  5. Jika ada selisih, isi Reason dengan alasan yang jelas.
  6. Klik Save per item, atau klik Save Drafts untuk menyimpan beberapa item sekaligus.
Step 6 - Import CSV
  1. Buka detail sesi dengan status Draft atau Counting.
  2. Klik Template CSV.
  3. Isi file CSV sesuai template. Jangan mengubah kode material.
  4. Klik Import CSV dan pilih file yang sudah diisi.
  5. Periksa kembali item yang terimport sebelum submit review.
Step 7 - Review Variance
  1. Buka tab Variance.
  2. Periksa item dengan status Surplus atau Shortage.
  3. Pastikan semua item variance memiliki alasan.
  4. Jika perlu hitung ulang, gunakan aksi Request Recount pada item terkait.
Step 8 - Submit Review
  1. Pastikan seluruh item yang perlu dihitung sudah memiliki physical stock.
  2. Pastikan semua variance sudah diberi reason.
  3. Klik Submit Review.
  4. Status sesi berubah menjadi Review.
Step 9 - Submit Approval
  1. Setelah status Review, klik Submit Approval.
  2. Sistem membuat approval request berdasarkan workflow Material Stock Opname.
  3. Status sesi berubah menjadi Pending Approval.
  4. Buka tab Approval untuk melihat workflow, requester, status, dan log approval.
Step 10 - Approval
  1. Approver login ke Portal Asset.
  2. Buka menu My Approvals.
  3. Pilih approval dengan module Material Stock Opname.
  4. Periksa detail item dan variance.
  5. Klik Approve jika sesuai, atau Reject jika perlu ditolak.
Final approver tidak boleh menjadi pembuat, submitter, counter, atau reviewer item pada sesi yang sama jika aturan segregation of duties aktif.
Step 11 - Posting Adjustment
  1. Jika approval final disetujui, sistem memposting adjustment stok secara otomatis.
  2. Item surplus menghasilkan adjustment masuk.
  3. Item shortage menghasilkan adjustment keluar.
  4. Status sesi menjadi Posted.
  5. Stok material dan riwayat transaksi sudah terupdate.
Step 12 - Export dan Berita Acara
  1. Buka detail sesi.
  2. Klik Export CSV untuk laporan data opname.
  3. Jika status sudah Posted, klik Berita Acara untuk mengunduh PDF resmi.
  4. Simpan file untuk arsip estate dan audit internal.

7. Checklist Sebelum Submit Review

  • Semua item yang dihitung sudah memiliki physical stock.
  • Item dengan selisih sudah memiliki reason.
  • Item yang perlu recount sudah dihitung ulang atau diberi catatan.
  • Total variance sudah diperiksa oleh PIC estate/manager.
  • Tidak ada file CSV yang salah kode material atau salah estate.

8. Checklist Sebelum Approval

  • Workflow Material Stock Opname aktif.
  • Approver aktif dan memiliki role sesuai workflow.
  • Approver bukan user yang sama dengan pembuat, submitter, counter, atau reviewer sesi jika aturan pemisahan tugas aktif.
  • Variance shortage/surplus sudah masuk akal dan memiliki alasan.
  • Jika nilai variance besar, lampirkan catatan internal sesuai SOP perusahaan.

9. Troubleshooting

Masalah Kemungkinan Penyebab Solusi
Menu Stock Opname tidak muncul User belum punya permission view-material-stock-opnames, belum aktif, atau belum memiliki estate. Admin cek role/permission, jalankan migration permission jika belum, lalu user logout-login.
Akses URL kembali ke Dashboard Permission route tidak terpenuhi atau user belum setup akses operasional. Cek role, estate, not_active, dan permissions pada user.
New Session gagal Masih ada sesi aktif untuk estate/section yang sama. Selesaikan, cancel, atau posted sesi aktif sebelumnya.
Submit Review gagal Masih ada variance tanpa reason atau item belum lengkap. Lengkapi physical stock dan reason pada item variance.
Submit Approval gagal Workflow belum aktif atau approver tidak ditemukan. Admin cek menu Approval Workflows untuk module Material Stock Opname.
Approval final ditolak Approver memilih reject atau aturan segregation of duties dilanggar. Review ulang sesi, perbaiki proses, lalu buat sesi baru jika diperlukan.
Berita Acara tidak muncul Status belum Posted atau user tidak punya permission export. Tunggu approval final posted atau minta admin cek permission export-material-stock-opnames.

10. Catatan Audit

  • Semua perubahan item dan aksi sesi tercatat di tab Log.
  • Semua aksi approval tercatat di tab Approval.
  • Adjustment stok dibuat satu kali saat final approval berhasil.
  • Sesi Rejected atau Cancelled tidak mengubah stok material.
  • Gunakan PDF Berita Acara dari sesi Posted sebagai arsip resmi.
Dokumen ini disiapkan untuk pelatihan user dan operasional harian. Untuk perubahan workflow atau permission, gunakan menu Administration sesuai akses admin.
