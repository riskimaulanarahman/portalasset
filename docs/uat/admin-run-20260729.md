## Temuan Dan Perbaikan

1. Frontend build gagal karena beberapa TypeScript/config issue.
   Perbaikan:
   - `vite.config.ts` memakai `defineConfig` dari `vitest/config`.
   - Unused import/variable dibersihkan.
   - Typing form dan DataTable diperbaiki.

2. Form Material tidak selaras dengan backend.
   Dampak:
   - UI mengirim `cat_id`, backend membutuhkan `category_id`.
   - UI mengirim `part_no`, backend menyimpan `matcode`.
   Perbaikan:
   - Material form sekarang memakai `category_id` dan `matcode`.
   - Duplikasi field part number dihapus.

3. Workflow UI memakai module value `Transfers`, sementara backend transfer mencari `Transfer`.
   Dampak:
   - Workflow yang dibuat dari UI berpotensi tidak terpanggil saat transfer.
   Perbaikan:
   - Workflow form default dan option diubah ke `Transfer`.
   - Option `write-off` ditambahkan karena backend memakai module tersebut untuk write-off.

4. Seeder workflow memakai role `Manager` dan `Finance`, sementara role seed memakai lowercase `manager` dan `finance`.
   Dampak:
   - My Approvals tidak menemukan approver jika role_name case mismatch.
   Perbaikan:
   - `WorkflowSeeder` memakai `manager` dan `finance`.
   Catatan:
   - Data workflow existing di DB masih global lama dengan `Manager`/`Finance`; UAT memakai workflow estate-specific baru agar tidak mengubah data existing tanpa cleanup plan.

5. Transfer asset approved tidak memindahkan asset ke estate tujuan.
   Dampak:
   - Status transfer bisa `Approved`, tetapi master asset tetap di estate asal.
   Perbaikan:
   - Transfer service sekarang memproses type `Asset` dengan update `asset.estate_id` ke destination estate dan `unit_id` ke kode estate tujuan.
   - Approval final transfer mengisi `receive_date` untuk material dan asset.
   Retest:
   - Asset `AST-TRN-003` berpindah ke estate `U00`, `estate_id=9`, `unit_id=U00`.

6. Master Asset Type/Manufacturer/Asset Reg mengizinkan nilai lebih panjang dari snapshot asset.
   Dampak:
   - Master data valid tetapi gagal dipakai saat register asset karena kolom `assets.type`, `manufacture`, dan `series` lebih pendek.
   Perbaikan:
   - Validasi master diselaraskan dengan batas asset: Asset Type `25`, Manufacturer `50`, Series `25`.
